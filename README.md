# 🦷 Dentytech Landing Page

A modern and minimal **Dentytech dental landing page** built using HTML and CSS.

The project focuses on clean UI, image positioning, typography, navigation design, and CSS transformations.

## 🚀 Features

- Responsive navigation bar
- Dentytech brand logo
- Menu and hamburger icon
- Login and Sign Up buttons
- Large centered hero heading
- Layered and rotated image cards
- Social media icons
- Bottom informational text
- Hover effects
- Responsive design for smaller screens
- Remix Icon integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- Remix Icon
- Unsplash

## 🎨 Design

The page uses a minimal dental/healthcare-inspired design with:

* White background
* Black typography
* Orange Sign Up button
* Rounded buttons
* Rounded image cards
* Centered hero section
* Layered image composition

## 🖼️ Image Layout

The hero section contains four images positioned in the center of the page.

Each image is rotated at a different angle:

```text
Image 1 → -30°
Image 2 → -20°
Image 3 → -10°
Image 4 →   0°
```

This creates the stacked-card effect in the center of the page.

## 🔗 Icons

The project uses Remix Icon through its CDN.

Icons currently used:

* Menu
* Instagram
* YouTube
* Facebook

## 📱 Responsive Design

The page includes CSS media queries for different screen sizes:

* Desktop
* Tablet
* Mobile

The image sizes, heading size, navigation elements, and social icons adjust automatically on smaller screens.
